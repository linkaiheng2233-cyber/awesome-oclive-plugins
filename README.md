# OCLive 插件索引

用于发现 OCLive 插件与模块示例的公开目录。条目保存在 [plugins.json](plugins.json)，代码由各发布者的源码仓库维护。

This repository is a discovery index for OCLive plugins and examples, not a plugin runtime or a security certification service.

## 从哪里开始

- **使用 A.I.Live**：从 [主仓库](https://github.com/linkaiheng2233-cyber/oclivenewnew)和[用户手册](https://github.com/linkaiheng2233-cyber/oclivenewnew/blob/main/creator-docs/getting-started/USER_MANUAL.md)进入。
- **查看条目**：阅读 [plugins.json](plugins.json)，再到条目的 `git` / `gitSubdir` 核对源码、说明与支持的 Host。
- **编写插件**：从[插件作者学习路径](https://github.com/linkaiheng2233-cyber/oclivenewnew/blob/main/creator-docs/plugin-and-architecture/PLUGIN_AUTHOR_LEARNING_PATH.md)开始。

## 目录的边界

索引包含示例条目；收录不代表成品、兼容认证或安全审计。模型、侧车和权限需求由插件及所选 Host 的说明决定。各插件的许可由其源仓库声明。

本仓提供的是目录文件，没有独立安装程序，也不是已经部署的社区网站。社区站原型见 [oclive-plugin-market](https://github.com/linkaiheng2233-cyber/oclive-plugin-market)，其暂停状态与本目录分别维护。

## 提交与反馈

欢迎通过 [Issue](https://github.com/linkaiheng2233-cyber/awesome-oclive-plugins/issues)讨论新条目，再以 PR 修改 `plugins.json`。请提供可访问的来源、插件身份、版本、用途和适用 Host，保留现有字段结构；不把密钥或用户数据放进条目。

角色包目录见 [awesome-oclive-roles](https://github.com/linkaiheng2233-cyber/awesome-oclive-roles)。
